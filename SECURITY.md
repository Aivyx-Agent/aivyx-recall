# Security Policy

aivyx-recall is a library, not a standalone application — it provides
a storage-agnostic cross-session memory substrate, consumed today by
`aivyx-coder`. A vulnerability here is usually most consequential in
how it affects that consuming project, and should still be reported.

This is not a bug bounty program.

## Reporting a vulnerability

Report it privately on GitHub: [Report a vulnerability](https://github.com/Aivyx-Agent/aivyx-recall/security/advisories/new)
(this repo's **Security** tab). Only the maintainer sees the report
until a fix is published. Please don't open a public issue for a
vulnerability.

We aim to resolve or provide a remediation plan for a
confirmed vulnerability within 90 days of the report, or coordinate a
later disclosure date directly with the reporter if a fix genuinely
needs longer. Credit is offered in release notes at the reporter's
preference.
